### 问题根因

`questionnaire.html` 中所有 `querySelector` / `querySelectorAll` 的属性选择器使用了中文全角引号 `""`（U+201C/U+201D）而非标准 ASCII `"`（U+0022）。CSS 属性选择器 `[name="budget"]` 使用中文引号时，浏览器无法匹配 HTML 中的标准引号属性值，导致所有选择器返回 `null`/空，表单数据收集全部为空，校验必然失败。

**`handleSubmit` 函数本身始终存在**（第 393 行），问题不在函数丢失，而在内部选择器静默失效。

### 修复清单

| 行号 | 修复内容 |
|------|----------|
| 188 | `[name="health"]` |
| 198 | `[name="environment"]` |
| 224 | `showFieldError` 中 `[name="budget"]` |
| 238 | `showBudgetError` 中 `[name="budget"]` |

## 🐛 2026-07-22（Debug Session）

### 问题 1：前端「平台数据概览」和「目的地卡片」无法渲染

- **现象**：Hero 面板显示正常，但 Overview 停留在"数据加载中"，Cards 不渲染
- **排查**：追踪 main.js → api.js → overview.js 完整调用链
- **根因**：**后端 FastAPI 服务未启动**。Hero 之所以"正常"是因为 `loadHeroData()` 在 fetch 失败后静默显示 `--` 占位符，而 overview.js 收到空数组后显式显示"数据加载中"
- **修复**：启动后端服务即可，无需修改代码

### 问题 2：FastAPI 无法启动（ImportError: attempted relative import with no known parent package）

- **根因**：启动命令的工作目录不正确。项目使用 **统一 relative import**（`from .database import ...`），必须在项目根目录以 `backend.main:app` 方式启动
- **正确的启动方式**：
  ```powershell
  cd D:\ai_project\health_travel_agent
  .\venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
  ```
- **修复文件**：无（仅修正启动命令，不修改代码）
